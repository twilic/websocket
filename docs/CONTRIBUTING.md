# Contributing

Thank you for improving `@twilic/websocket`.

## Development

Requirements: Node.js 24+, pnpm 10+

javascript, typescript, json, and markdown formatting uses oxfmt with the shared ultracite preset.

```bash
pnpm install
pnpm build
pnpm test
pnpm fmt:check
pnpm lint
```
